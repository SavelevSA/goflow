# Контракт HTTP API GoFlow

Локальный сервер работает на `http://127.0.0.1:8080`. Клиент использует относительные пути. У запросов с телом нужно установить `Content-Type: application/json`. Успешный ответ каждого маршрута — `200 OK` и актуальный Snapshot в JSON. Команда возвращает снимок после внесения изменений. Клиент может опрашивать `/api/state` примерно раз в 300 мс.

| Метод | Путь | Тело | Действие |
|---|---|---|---|
| GET | `/api/state` | — | Получить состояние |
| POST | `/api/mode` | `{"mode":"adaptive"}` | Выбрать `fixed` или `adaptive` |
| POST | `/api/density` | `{"density":3}` | Установить целую интенсивность от 1 до 5 |
| POST | `/api/pause` | `{"paused":true}` | Поставить на паузу или продолжить (`false`) |
| POST | `/api/reset` | `{"seed":42}` | Сбросить такт, машины, очереди, фазы и счётчики с заданным seed. Сохраняются режим, интенсивность и состояние паузы |

| Код | Причина |
|---|---|
| `400` | Некорректный JSON, пропущенное поле или недопустимое значение |
| `404` | Неизвестный путь API |
| `405` | Неверный метод. Ответ содержит заголовок `Allow` |
| `500` | Внутренняя ошибка сервера |

Тело ошибки имеет формат `{"error":"описание"}`. В каркасе первого дня работает тестовый `GET /api/state`. Маршруты POST описывают контракт для разработки клиента.

## Snapshot

```json
{
  "tick": 12,
  "mode": "fixed",
  "density": 3,
  "paused": false,
  "seed": 42,
  "vehicles": [{"id": 1, "x": 20, "y": 25, "direction": "east", "waiting": true, "waitingTime": 1}],
  "intersections": [
    {"id": 1, "x": 25, "y": 25, "phase": "ns", "queueNS": 0, "queueEW": 1, "phaseElapsed": 3},
    {"id": 2, "x": 75, "y": 25, "phase": "ns", "queueNS": 0, "queueEW": 0, "phaseElapsed": 3},
    {"id": 3, "x": 25, "y": 75, "phase": "ns", "queueNS": 0, "queueEW": 0, "phaseElapsed": 3},
    {"id": 4, "x": 75, "y": 75, "phase": "ns", "queueNS": 0, "queueEW": 0, "phaseElapsed": 3}
  ],
  "statistics": {"totalSpawned": 1, "totalCompleted": 0, "activeVehicles": 1, "totalQueue": 1, "averageWaitingTime": 0}
}
```

- Координаты `x` и `y` лежат в диапазоне `0..100`. `x` увеличивается вправо, `y` вниз. Центры перекрёстков заданы точками `(25,25)`, `(75,25)`, `(25,75)`, `(75,75)`.
- `direction` принимает `north`, `south`, `east`, `west`. Фаза `ns` даёт зелёный северу и югу, `ew` — востоку и западу.
- `tick` — число шагов от старта или сброса. `phaseElapsed`, `waitingTime` и `averageWaitingTime` измеряются в секундах симуляции.
- `waitingTime` накапливается за всю поездку автомобиля. `averageWaitingTime` — среднее по завершённым поездкам с учётом поездок без ожидания. До первой завершённой поездки среднее равно нулю.
- `totalQueue` — количество ожидающих автомобилей. Пустые коллекции передаются как `[]`.
- Для сравнения режимов используйте одинаковые seed, интенсивность и число шагов.
